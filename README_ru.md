Etonify: VPN-клиент с открытым исходным кодом для Android. Приложение написано на Flutter и использует [etonify-core](https://github.com/yamixdev/etonify-core), поддерживаемый форк sing-box. В клиенте можно управлять подписками, выбирать серверы, настраивать DNS и маршрутизацию трафика.

Приложение не предоставляет VPN-серверы. Для подключения нужен собственный сервер или подписка провайдера.

## Версии и требования

| Компонент | Версия или требование |
| :--- | :--- |
| Версия клиента в исходниках | `0.3.6+26` |
| Встроенное ядро | `v1.15.0-alpha.3-etonify.5` на базе sing-box `1.15.0-alpha.3` |
| Flutter SDK | `3.47.2` (Dart 3.13) |
| Android | 8.0 и новее (API 26+) |
| Архитектуры APK | `arm64-v8a`, `armeabi-v7a` |
| Языки интерфейса | Русский и английский |

Версия клиента указана в [pubspec.yaml](pubspec.yaml), версия встроенного ядра: в [libbox.provenance.json](android/app/libs/libbox.provenance.json). В исходниках могут быть еще не выпущенные изменения. Доступные APK и описание каждого выпуска находятся в [Releases](https://github.com/yamixdev/Etonify/releases).

Поддерживаемая платформа выпуска: Android. Наличие каталогов других платформ Flutter не означает, что для них доступны рабочие сборки.

## Как начать

1. Скачайте подходящий для устройства APK из Releases и установите его.
2. Добавьте подписку или импортируйте конфигурацию сервера.
3. Выберите сервер или группу автоматического выбора.
4. Включите подключение и подтвердите системный запрос Android на создание VPN.

Обновления доступны в разделе **О приложении > Обновления**. В меню этого раздела можно выбрать канал **Stable** или **Beta**. В Beta доступны предварительные выпуски для тестирования. Приписки «beta» в отображаемой версии приложения может не быть.

## Возможности

- **Подключение:** системный VPN через TUN, локальный HTTP/SOCKS-прокси или оба режима одновременно.
- **Подписки:** импорт по ссылке, из файла, буфера обмена, QR-кода или поддерживаемого диплинка; обновление профилей и просмотр сведений о трафике и сроке действия, если их передаёт провайдер.
- **Серверы:** ручной и автоматический выбор, цепочки прокси и проверка задержки через прокси-соединение.
- **Маршрутизация:** выбор приложений, обход локальной сети, правила трафика и локальные наборы правил.
- **DNS:** прямые и проксируемые резолверы, защищённый DNS и DNS-фильтр AdGuard.
- **Настройки ядра:** стратегия выбора сети, таймауты соединений, TCP Keep Alive и параметры UDP/NAT. В разделе есть пояснения, предупреждение при первом входе и отдельный сброс. Подробнее в [описании настроек ядра](docs/core-settings.md).
- **Диагностика:** журнал соединений и сведения о работе приложения и ядра.

Проверка задержки выполняет запрос через прокси, а не ICMP-пинг. Отсутствие результата само по себе ещё не означает, что сервер не работает.

## Совместимость конфигураций

Клиент импортирует ссылки на серверы, sing-box JSON, Xray JSON, Clash YAML и SIP008. Поддерживаются VLESS, VMess, Trojan, Shadowsocks, Hysteria/Hysteria2, TUIC, AnyTLS, NaiveProxy, HTTP и SOCKS. Совместимость зависит от протокола, транспорта и параметров конфигурации.

Импорт профиля Xray или Clash не означает поддержку всех возможностей исходного ядра. Etonify преобразует поддерживаемые параметры в собственную конфигурацию sing-box. Изменения формата описаны в [документации по совместимости с sing-box 1.14](docs/schema-1.14-compatibility.md).

WireGuard не поддерживается начиная с Etonify 0.3.1 из-за проблем с работой этого протокола в клиенте.

Мультиплексирование требует поддержки со стороны сервера. Клиент не может автоматически включить его для любого подключения, а мультиплексирование sing-box не взаимозаменяемо с Xray Mux. Настройки провайдера и ручное переопределение описаны в разделе настроек ядра.

## Конфиденциальность и безопасность

- Параметр **Отправка HWID провайдеру** в общих настройках управляет глобальной отправкой данных об устройстве при запросах подписок. Для отдельных подписок также может быть сохранено согласие. Проверьте эти настройки перед добавлением подписки.
- Разрешение недоверенных сертификатов прокси находится в настройках безопасности. Оно отключает проверку сертификата и не должно использоваться как универсальное решение проблем с подключением.
- Логи и скриншоты могут содержать ссылки подписок, адреса серверов, учётные данные и идентификаторы устройства. Проверяйте вложения перед отправкой, даже если приложение уже скрыло часть данных.

Об уязвимостях сообщайте приватно по инструкции в [SECURITY.md](SECURITY.md), а не через публичный issue.

## Сборка и разработка

CI клиента использует Flutter `3.47.2` и JDK `21`. Требования к Dart заданы в [pubspec.yaml](pubspec.yaml), а версии инструментов Android указаны в файлах Gradle. Для сборки ядра используется отдельный набор инструментов, указанный в [ETONIFY_BASELINE](etonify-core/release/ETONIFY_BASELINE).

```powershell
git clone --recurse-submodules https://github.com/yamixdev/Etonify.git
cd Etonify
flutter pub get
flutter gen-l10n
flutter analyze
flutter test
flutter build apk --debug
```

Для релизной сборки настройте ключ подписи в `android/key.properties`. Часть ресурсов для совместимости с зашифрованными подписками Happ не публикуется. Учитывайте [требования к закрытым ресурсам сборки](.github/private/README.md), если проверяете эту возможность в локальной сборке.

Коммит исходников, версия, инструменты сборки и контрольная сумма встроенного AAR записаны в [libbox.provenance.json](android/app/libs/libbox.provenance.json). Текущий HEAD подмодуля не обязательно совпадает с исходниками встроенного бинарника. Требования к его замене приведены в [документации ядра](android/app/libs/README.md), а правила участия в разработке находятся в [CONTRIBUTING.md](CONTRIBUTING.md).
