В Etonify можно добавлять подписки, выбирать серверы, настраивать маршруты и проверять подключение. Есть светлая и тёмная темы, а также цвета из системной палитры Android.

> [!IMPORTANT]
> Etonify не предоставляет VPN-серверы и не продаёт подписки. Для подключения нужен собственный сервер или подписка провайдера.

<a id="features"></a>

## Возможности

| Раздел | Что можно делать |
| :--- | :--- |
| Подписки | Импортировать по ссылке, из файла, буфера обмена, QR-кода или поддерживаемого диплинка. Обновлять профили и смотреть трафик и срок действия, если их передаёт провайдер. |
| Серверы и группы | Выбирать сервер вручную или использовать автогруппу. Просматривать вложенные группы в порядке подписки, делиться сервером или группой и экспортировать профиль в JSON для импорта из файла. |
| Проверка задержки | Проверять сервер, участников группы или подписку. Смотреть результаты и счётчики рабочих серверов, не считая непроверенные серверы нерабочими. |
| Маршрутизация | Выбирать приложения для работы через VPN или напрямую. У каждого режима свой список. Настраивать правила трафика, обход локальной сети и локальные наборы правил. |
| Мониторинг трафика | Следить за скоростью загрузки и отдачи, трафиком сессии и временем работы. Обновлять текущий внешний IP и флаг его страны. |
| DNS и настройки ядра | Настраивать прямой и проксируемый DNS, защищённый DNS и фильтр AdGuard. Менять стратегию выбора сети, таймауты, TCP Keep Alive и параметры UDP/NAT. |
| Подключение и диагностика | Использовать Android VPN через TUN, локальный HTTP/SOCKS-прокси или оба режима. Смотреть логи, совместимость ядра, состояние применённого конфига и ресурсы процесса. |

Задержка измеряется запросом через прокси, а не обычным ICMP-пингом. Отсутствие результата само по себе не означает, что сервер не работает. Счётчики учитывают завершённые проверки участников групп.


<a id="quick-start"></a>

## Подключение за четыре шага

1. Установите подходящий для устройства APK из [Releases](https://github.com/yamixdev/Etonify/releases).
2. Добавьте подписку или импортируйте конфигурацию сервера.
3. Выберите сервер или группу автоматического выбора.
4. Включите подключение и подтвердите системный запрос Android на создание VPN.

В разделе **О приложении → Обновления** выберите **Stable** или **Beta** через меню. В Beta доступны предварительные выпуски для тестирования; приписки «beta» в отображаемой версии может не быть.

Если после обновления появилось сообщение о сбросе раздельной маршрутизации, зайдите в раздел и заново выберите приложения перед её включением.

<a id="compatibility"></a>

## Совместимость конфигураций

**Форматы импорта**

`sing-box JSON` · `Xray JSON` · `Clash YAML` · `SIP008` · ссылки на серверы

**Протоколы**

`VLESS` · `VMess` · `Trojan` · `Shadowsocks` · `Hysteria / Hysteria2` · `TUIC` · `AnyTLS` · `NaiveProxy` · `HTTP` · `SOCKS`

Etonify преобразует поддерживаемые параметры Xray и Clash в собственную конфигурацию sing-box. Импорт профиля не включает все возможности исходного ядра. Совместимость зависит от протокола, транспорта и используемых полей.

- WireGuard не включён в Android-сборку.
- Мультиплексирование требует поддержки со стороны сервера. Мультиплексирование sing-box и Xray Mux не взаимозаменяемы.
- Вложенность групп определяется ссылками в конфигурации, а не названиями вроде `cand-*`. При экспорте группы сохраняются её участники и связанные зависимости.

Подробнее: [выбор прокси и вложенные группы](docs/proxy-selection-contract.md), [настройки ядра и мультиплексирование](docs/core-settings.md), [предыдущие изменения схемы sing-box](docs/schema-1.14-compatibility.md).

## Конфиденциальность и безопасная отправка

Etonify подключается к выбранным вами VPN-серверам. Трафик не проходит через серверы MeowTeam. В клиенте нет рекламных и аналитических SDK.

- **На устройстве:** подписки, профили, настройки, логи и скачанные правила остаются локально. На Android базы подписок и настроек зашифрованы. Ключ защищён Android Keystore, системным хранилищем ключей. Экспортированные файлы эта защита не покрывает.
- **Разработчикам:** клиент не отправляет профили и диагностические логи автоматически. Передавая их в поддержку, вы сами выбираете, какие данные отправить.
- **Внешним сервисам:** подписка загружается по указанной ссылке. Обновления, правила и картинки из истории изменений загружаются с GitHub и других источников, указанных в приложении. Проверка задержки использует тестовый URL из настроек. DNS-запросы отправляются выбранному DNS-серверу. Эти сервисы видят IP-адрес, с которого приходит запрос.
- **«Ваш IP»:** для определения внешнего адреса и страны клиент обращается к Cloudflare при открытии панели или ручном обновлении. Запрос идёт по текущим маршрутам устройства, с учётом VPN и раздельной маршрутизации.

VPN сам по себе не гарантирует анонимность. Какие данные видят VPN-провайдер и DNS-сервис, зависит от протокола, шифрования и настроек.

- Отправка HWID (идентификатора устройства) включена по умолчанию. Её можно выключить в общих настройках, но отдельная подписка может иметь своё разрешение на отправку. Проверьте также настройки подписки и добавленные вручную заголовки запроса.
- Разрешение недоверенных сертификатов прокси отключает проверку сертификата. Не используйте его как универсальное решение проблем с подключением.
- Экспорт профилей, резервные копии, логи и скриншоты могут содержать ссылки подписок, ключи доступа, пароли, адреса серверов и идентификаторы устройства. Проверяйте и скрывайте эти данные перед отправкой.

Об уязвимостях сообщайте приватно через контакты в [SECURITY.md](SECURITY.md). Не публикуйте подробности эксплуатации в открытом issue.

## Разработка

Клиент использует AAR из репозитория: обычная сборка приложения не пересобирает Go-ядро. В CI используются Flutter `3.47.5` и JDK `21`; также нужны Android SDK и Python 3.

<details>
<summary>Подготовка клиента, проверки и debug-сборка</summary>

```powershell
git clone --recurse-submodules https://github.com/yamixdev/Etonify.git
cd Etonify
flutter pub get
flutter gen-l10n
dart run pigeon --input pigeons/singbox_api.dart
python scripts/verify_libbox.py
flutter analyze
flutter test
flutter build apk --debug
```

Для релизной сборки настройте подпись в `android/key.properties`. Официальные сборки могут восстанавливать закрытые ресурсы для зашифрованных подписок Happ; учитывайте [требования к закрытым ресурсам](.github/private/README.md), если хотите проверить эту совместимость локально.

</details>

<details>
<summary>Как зафиксировано встроенное ядро</summary>

Сабмодуль фиксирует исходники ядра. Android собирается с `android/app/libs/libbox.aar`. Их нужно обновлять вместе с JAR исходников, контрольной суммой и метаданными сборки. `scripts/verify_libbox.py` проверяет совпадение коммитов и контракт Android Java API.

Правила замены ядра: [документация встроенного AAR](android/app/libs/README.md). Отдельные инструменты сборки ядра: [ETONIFY_BASELINE](etonify-core/release/ETONIFY_BASELINE). Автоматизация выпусков: [руководство по GitHub Actions](docs/github-actions.md).

</details>
