Etonify поєднує підписки, вибір проксі, маршрутизацію та діагностику підключення в одному застосунку для Android. Інтерфейс підтримує світлу, темну тему й динамічні кольори.

> [!IMPORTANT]
> Etonify не надає VPN-серверів і не продає підписки. Для підключення потрібен власний сервер або підписка провайдера.

<a id="features"></a>

## Можливості

| Розділ | Що можна робити |
| :--- | :--- |
| Підписки | Імпортувати за посиланням, із файлу, буфера обміну, QR-коду або підтримуваного диплінка. Оновлювати профілі й переглядати трафік та строк дії, якщо їх передає провайдер. |
| Сервери та групи | Вибирати сервер вручну або використовувати автоматичну групу. Переглядати вкладені групи в порядку підписки, ділитися сервером чи групою та експортувати профіль у JSON для імпорту з файлу. |
| Перевірка затримки | Перевіряти сервер, учасників групи або підписку. Переглядати результати та лічильники робочих серверів, не вважаючи неперевірені сервери неробочими. |
| Маршрутизація | Вибирати застосунки для роботи через VPN або напряму. Кожен режим має окремий список. Налаштовувати правила трафіку, обхід локальної мережі та локальні набори правил. |
| Моніторинг трафіку | Стежити за швидкістю завантаження й віддавання, трафіком сеансу та часом роботи. Оновлювати поточну зовнішню IP-адресу й прапор її країни. |
| DNS і налаштування ядра | Налаштовувати прямий та проксійований DNS, захищений DNS і фільтр AdGuard. Змінювати стратегію вибору мережі, таймаути, TCP Keep Alive та параметри UDP/NAT. |
| Підключення й діагностика | Використовувати Android VPN через TUN, локальний HTTP/SOCKS-проксі або обидва режими. Переглядати логи, сумісність ядра, стан застосованої конфігурації та ресурси процесу. |

Перевірка затримки надсилає запит через проксі, а не ICMP-пінг. Відсутність результату не означає виміряний збій. Результати груп і лічильники залежать від завершених перевірок їхніх учасників.

## Підключення за чотири кроки

1. Установіть APK для свого пристрою з [Releases](https://github.com/yamixdev/Etonify/releases).
2. Додайте підписку або імпортуйте конфігурацію сервера.
3. Виберіть сервер або групу автоматичного вибору.
4. Увімкніть підключення й підтвердьте системний запит Android на створення VPN.

У розділі **Про застосунок → Оновлення** виберіть **Stable** або **Beta** через меню. Beta містить попередні випуски для тестування; відображена версія може не мати суфікса «beta».

Якщо після оновлення з'явилося повідомлення про скидання роздільної маршрутизації, перегляньте розділ і заново виберіть застосунки перед її ввімкненням.

<a id="compatibility"></a>

## Сумісність конфігурацій

**Формати імпорту**

`sing-box JSON` · `Xray JSON` · `Clash YAML` · `SIP008` · посилання на сервери

**Протоколи**

`VLESS` · `VMess` · `Trojan` · `Shadowsocks` · `Hysteria / Hysteria2` · `TUIC` · `AnyTLS` · `NaiveProxy` · `HTTP` · `SOCKS`

Etonify перетворює підтримувані параметри Xray та Clash на власну конфігурацію sing-box. Імпорт профілю не вмикає всі можливості його початкового ядра. Сумісність залежить від протоколу, транспорту й використаних полів.

- WireGuard не включено до Android-збірки.
- Мультиплексування потребує підтримки сервера. Мультиплексування sing-box і Xray Mux не є взаємозамінними.
- Вкладеність груп визначається посиланнями в конфігурації, а не назвами на зразок `cand-*`. Експорт групи зберігає її учасників і пов'язані залежності.

Докладніше: [вибір проксі та вкладені групи](docs/proxy-selection-contract.md), [налаштування ядра й мультиплексування](docs/core-settings.md), [попередні зміни схеми sing-box](docs/schema-1.14-compatibility.md).

<a id="privacy"></a>

## Конфіденційність і безпечне поширення

Etonify підключається до вибраних вами VPN-серверів. Трафік не проходить через сервери MeowTeam. У клієнті немає рекламних чи аналітичних SDK.

- **На пристрої:** підписки, профілі, вибрані сервери, налаштування, діагностичні логи та завантажені правила обробляються локально. На Android бази підписок і налаштувань шифруються ключем, захищеним Android Keystore. Це не шифрує експортовані файли.
- **Розробникам:** клієнт не надсилає профілі та діагностичні логи автоматично. Звертаючись до підтримки, ви самі вибираєте, які дані надіслати.
- **Зовнішнім сервісам:** підписка завантажується за вказаним посиланням. Оновлення, правила та зображення журналу змін завантажуються з GitHub та інших джерел, указаних у застосунку. Перевірка затримки використовує тестовий URL із налаштувань. DNS-запити надсилаються вибраному DNS-серверу. Ці сервіси бачать IP-адресу, з якої надходить запит.
- **«Ваша IP-адреса»:** для визначення зовнішньої адреси та країни клієнт звертається до Cloudflare під час відкриття панелі або ручного оновлення. Запит іде поточними маршрутами пристрою, з урахуванням VPN і роздільної маршрутизації.

VPN сам по собі не гарантує анонімності: доступні провайдерам VPN і DNS дані залежать від протоколу, шифрування та ваших налаштувань.

- Глобальне надсилання HWID типово ввімкнене; його можна вимкнути в налаштуваннях. Якщо загальне налаштування вимкнене, згода для окремої підписки все ще може дозволяти надсилання для цього профілю. Перевірте загальні налаштування, налаштування підписки та власні заголовки перед додаванням.
- Дозвіл недовірених сертифікатів проксі вимикає перевірку сертифіката. Не використовуйте його як універсальне виправлення проблем із підключенням.
- Експорт профілів, резервні копії, логи та знімки екрана можуть містити посилання підписок, ключі доступу, паролі, адреси серверів або ідентифікатори пристрою. Перевіряйте й приховуйте ці дані перед поширенням.

Про вразливості повідомляйте приватно через контакти в [SECURITY.md](SECURITY.md). Не публікуйте подробиці експлуатації у відкритому issue.

## Розробка

Клієнт використовує AAR із репозиторію: звичайна збірка застосунку не перезбирає Go-ядро. CI використовує Flutter `3.47.5` і JDK `21`; також потрібні Android SDK та Python 3.

<details>
<summary>Підготовка клієнта, перевірки й debug-збірка</summary>

```powershell
git clone --recurse-submodules https://github.com/yamixdev/Etonify.git
cd Etonify
flutter pub get
flutter gen-l10n
dart run pigeon --input pigeons/singbox_api.dart
python scripts/verify_libbox.py
flutter analyze
flutter test
flutter build apk --debug
```

Для релізної збірки налаштуйте підпис у `android/key.properties`. Офіційні збірки можуть відновлювати закриті ресурси для зашифрованих підписок Happ; прочитайте [вимоги до закритих ресурсів](.github/private/README.md), якщо хочете перевірити цю сумісність локально.

</details>

<details>
<summary>Як зафіксовано вбудоване ядро</summary>

Сабмодуль фіксує вихідний код ядра. Android компілюється з `android/app/libs/libbox.aar`. Їх потрібно оновлювати разом із JAR вихідного коду, контрольною сумою та метаданими збірки. `scripts/verify_libbox.py` перевіряє відповідність комітів і контракт Android Java API.

Вимоги до заміни ядра: [документація вбудованого AAR](android/app/libs/README.md). Окремі інструменти збірки ядра: [ETONIFY_BASELINE](etonify-core/release/ETONIFY_BASELINE). Автоматизація випусків: [посібник із GitHub Actions](docs/github-actions.md).

</details>

Перед надсиланням змін прочитайте [CONTRIBUTING.md](CONTRIBUTING.md).
